# Reference notebook visual grammar

## Status

Accepted.

## Decision ID

`atrament.style.reference-notebook-visual-grammar`

## Context

The supplied notebook photographs vary from colorful decorative pages to sober
single-pen biology notes. Their useful common structure is not any exact title,
drawing, palette, or composition but a visual grammar that makes dense school
material readable and intentionally handmade.

## Decision

Atrament extracts reusable relationships rather than copying a reference page.
The initial grammar supports one dominant title, visible section hierarchy,
short text columns, bounded tables, highlighted key phrases, compact diagrams,
labels, arrows, deliberate whitespace, and measured alignment with controlled
ruler and handwriting imperfection.

Digital themes may use a small coordinated palette, layered title lettering,
marker strips, soft shadows, and decorative motifs. Live themes reduce the same
hierarchy to one pen through scale, weight, spacing, boxes, underlines, and
line-art diagrams.

Reference photographs are design evidence, not bundled product assets or
templates to trace. Generated pages must respond to the actual content, paper,
language, and output capability profile.

## Consequences

- Complex assignments can look organized without becoming generic worksheets.
- Decorative density remains a theme parameter rather than a fixed requirement.
- Drawings prioritize communicative line art over ornamental detail.
- Digital and live themes share hierarchy while differing in available media.

## Rejected Alternatives

- Reproducing one supplied page was rejected because the references contain
  unrelated subjects, creators, and visual choices.
- Random decoration was rejected because it competes with the assignment.
- Perfect computer-drawn boxes and grids were rejected because the target
  grammar includes bounded human variation.

## Verification

Review fixtures must include a dense two-column page, a table-led page, a
diagram-led page, a colorful digital page, and a sober live page. Reviewers must
identify the same semantic hierarchy without requiring copied motifs or text.
